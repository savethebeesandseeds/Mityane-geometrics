This complete owned copy of the final V4 attempt003 auditor reads saved data
with a restricted inert archive reader. It imports no Torch module and executes
no encoder, decoder, head, optimizer or fit. All historical sources remain.

The prospective audit card fixes native40,76 learned tensors,97 admitted main
sources,4096 TRAIN calibration windows,2048/B8,actual typed resume512 and saved
query reductions. It verifies version-aware fresh bank provenance rather than
requiring an earlier encoder's normalization identity. Actual CUDA gradients
and live resume are source-bound producer evidence; saved tensor movement,
statistics, counters, moments and query arithmetic are inspected independently.

Run only in the existing managed cuwacunu container, after the selected audit
card and source hashes are frozen and the main artifacts exist. Use the card's
explicit CLI and a new output file. Preserve failed attempts; never replay a
trajectory or fit as a format fallback. This tooling is outside the frozen
encoder/trainer/evaluation source capsule.
