metadata repair. They are outside the producer's frozen compiled source closure.

is rerun by this copy operation; no quality archive is included here.

The producer finalized the inventory by sorting Path objects, then converting
them to relative names. That is component order: `a/z.txt` precedes `a-y.txt`,
and `source/code/x.cpp` precedes `source-fingerprint.txt`. The original reader
and release command expected whole-string order and the first release stopped
with zero archive decodes. The failure record is preserved here.
