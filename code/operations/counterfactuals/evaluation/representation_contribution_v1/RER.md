# Requirements and evidence: representation contribution

**ID:** `OR06-REP-CONTRIB-001-RER`, version `1.0.0`.
**Contract:** [OR06-PCR 0.1.0](../../CONTRACT.md).
**Protocol:** [OR06-REP-CONTRIB-001 1.0.0](PROTOCOL.md).

The research unit is the fixed feature map, TRAIN-fitted target readout and
alternative-minus-baseline response on the protocol's static synthetic population.
Required properties are preservation of changed information, numerical finite
coordinates, declared nonlinear feature semantics and sufficient support.
The first four families preserve the same raw a,b information but differ in
what a five-parameter affine head can express; lossy deliberately violates
changed-information retention. Coordinate dimension is not space identity.

Provider identities are `OR06-REP-CONTRIB-001/<family>/1.0.0`; each binds the
prospective formula, source capsule and four-coordinate ordering. Each axis is
a separate response target/version, and each seed/axis/family model has its own
retained coefficient/scaler rows and byte-bound model artifact. Native output
is one scalar response per axis; paired output is its finite difference. No
cross-family coordinate subtraction is performed. TRAIN-only means and population
standard deviations are part of the fitted model, not shared preprocessing.

The actual instance is bound by the runner's `freeze.json`, captured configuration,
prior-exposure exclusions, `seal.json` and saved generator/input/model/prediction
records. `assessment-open.json` binds all sealed heads before assessment generation.
The independent audit verifies data generation, exclusions, TRAIN-only fits,
native features, predictions, contrasts, truth, roster, coverage and grouped
paired uncertainty. It has an intentionally corrupted-record rejection check
on the separate engineering population. Audit invalidity is not scientific
negative evidence. Exact commands and final identities belong in RESULTS.md.

Admission is the user's explicit request to finish existing Hx06 goals, implemented
as this finite CPU synthetic follow-up. All actual attempts are retained in the
append-only local ledger. No external data/model license or service permission
is needed: generated observations/maps are project-authored under MIT. No secret,
raw dataset, generated model or output is included in Git.

Failure/refusal conditions: unsupported alternative => `out_of_support` abstention
with no delta; malformed/nonfinite input, unsupported model identity/shape,
nonpositive scale, singular normal equation, source/model mutation, duplicate
output destination or incorrect complete roster => invalid execution/admission,
not selective omission. All seeds/families and negative results must be reported.
There is no temporal, observational identification, causal or individual-effect
claim. Fixed task-aligned features are sensitivity controls, not evidence of a
trained encoder's general utility. Prior familiarity with the original formula
and result is explicit. Fresh observations do not erase that exposure.

The readout decision is a required closeout artifact. The original OLS models and
evidence remain immutable. The new decision must state accepted method/binding
identities, validation limits, known misspecification failures and consequences
for dependent profiles. No OLS dependency is introduced into the independently
bound observational/intervention NSW reference instances.
