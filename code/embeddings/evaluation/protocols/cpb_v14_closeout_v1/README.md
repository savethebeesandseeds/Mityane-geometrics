`versions/instances/CPB-v14.market-01.json` and
`code/embeddings/evaluation/records/CPB-v14.market-01.closeout.json`. The archived
ledger remains unchanged. Current guide/dashboard links are the documentary
targets named by the admission and plan. No Git commit or push is included.

Use exclusive receipt/output names. A failure retains its source, inputs and
partial outputs; a repair receives a new identified generation. Missing evidence,
unknown repository scope, contradictory byte identities, changed before-state
or failed independent review blocks application. Preserve the failed result;
never fabricate a passed receipt or fall back to a similarly named live source.

Completion requires an actual passed proposal review, independently reviewed
staged changes, recorded application, focused validation, dashboard refresh and
final preservation. File existence, successful source tests or an admission
alone establishes none of those outcomes.
