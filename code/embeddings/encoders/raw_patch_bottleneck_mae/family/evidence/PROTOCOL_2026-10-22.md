# Hx16 portable RPB engineering verification

Protocol: `rpb-family-portability-v1`, 22 October 2026.
Authorization: the human owner's request to pursue the complete
`encoder-rpb-portable-training-delivery` Goal after accepting its source audit.
This protocol binds bounded artificial component checks. It supplies no encoder
quality, market, transfer, forecasting or application-admission claim.

## Scope and bindings

Test the maintained fresh RPB-v22 family surface over the existing v20 backbone,
shared `StreamingScaler`, original patch-mask/Huber arithmetic and unchanged
typed v22 inference/training-state codecs. Use only freshly generated artificial
observations, fresh weights and own disposable test states. Retain the audit,
all historical source/checkpoints/protocols and native36/V30 standings unchanged.

The two numerical configurations are:

| Name | Geometry and capacity | Native layout |
| --- | --- | --- |
| single | C1/H65/F3/P8/D8/W16, one layer, four heads, FF32, decoder16 | learned8; no cross-channel fixed tail |
| multi | C3/H129/F9/P8/D32/W32, one layer, four heads, FF64, decoder32 | learned20 + fixed12 |

The 22 October check used semantic IDs 11+7*c; interval1; CUDA:0, float32 model and existing float64
relation arithmetic. From 2026-10-29 the fixture names channels as cuwacunu_torch kline ordinals. The first two remain 11 (4h) and 18 (1M). The third is 4 (1m) rather than 25. Configuration files bind remaining numerical settings.
Fit the raw scaler only on declared artificial TRAIN, in source order and named
batch chunks. Fitting uses the shared supported-value-anchor/Chan algorithm;
partition/reference comparisons use explicit float64 tolerances. Exact resume
uses identical frozen scaler bytes, source/split/recipe identity and runtime.

Reference update recipe: original whole-patch masker; waveform hierarchical
Huber through the served global native export; detached standardized targets;
fixed AdamW lr0.001/decay0.0001/betas0.9,0.999/eps1e-8/AMSGrad off; global clip1;
no extra context deletion, accumulation or scheduler. Initialization and row/
mask/context seeds are explicit. Rows use MT19937_64 seeded from
`splitmix64-counter-v1` absolute attempts and modulo selection with replacement.
Skipped ineligible attempts advance attempts only. All seed values and exact
sampling semantics are recorded in the generated test/run reports. Save only
between attempts; total stop budgets may increase on example resume.

## Required checks

1. Fresh construction and derived native/parameter inventories at both configs;
   streamed TRAIN fit, finite forward, meaningful learned gradient/weight change,
   literal fixed-tail preservation and exact inference export/reload.
2. Interrupted versus uninterrupted next rows/masks/loss/gradients/model/AdamW/
   scaler/counters under the declared same runtime. Exercise an ineligible skip
   without optimizer action. Record actual physical optimizer actions separately
   from each logical trajectory's completed updates.
3. Reject invalid geometry/IDs/intervals, observed nonfinite/overflow, missing
   TRAIN support, changed logical history with equal padding, config/scaler/
   identity/seed/device/state drift, remapped/changed optimizer and existing output.
   Preserve absent-cell poison sanitization, target support and allmissing
   zero/invalid output. End-of-window context may use the full retained window;
   no prefix-causal assertion is made.
4. Native example: generate small typed artificial observation archives; run
   continuous and split/resumed trajectories at both configs; compare numerical
   state identities and resumed events, exercise valid TEST-role refusal,
   allmissing TRAIN-fit refusal, insufficient-patch-support attempt exhaustion/
   recovery, wrong seeds/scaler and immutable input/
   output behavior. Export embeddings with masks, support and provenance.
5. Source package: complete quoted local-include closure, origin/destination
   hashes, source/license/config/recipe/test inventory and offline external-pin
   verification; reject tamper/unsafe paths/symlinks/overwrite/missing dependencies.
   Compile and run bounded acceptance using only exported sources in a named
   isolated container directory through a recipient build harness. No sibling
   research checkout is a numerical dependency.

Each numerical trajectory uses only a few optimizer actions and small synthetic
populations; this is not a scientific study or substantial training. Failed
attempts, source repairs and reruns remain identifiable. Final evidence records
the actual commands, source/config/runtime/binary/output pins, physical actions,
refusal counts, coverage and exact-continuation limits. A source repair creates
a new source identity and requires the affected checks again.

## Execution and acceptance

Use the existing managed Linux container `mityane-geometrics` exclusively via
`container.ps1` and `code/scripts/task.sh`, with a named `hx16-rpb-portable-*`
build/output session. Builds/tmp stay under `/opt/mityane-geometrics`; selected
runs/export artifacts stay under ignored `.temp/embeddings/`. Inspect shared GPU
capacity first and verify actual CUDA in the fixture. Do not install dependencies,
alter lifecycle, load historical trained parents, replay scores or mutate an
application. Root build changes are limited to opt-in target integration.

Pass only when every advertised check succeeds and evidence is bound to the
actual final source. Missing support must be recorded as a gap; no research
winner is selected. Raw inference/training state remains separate from consumer
data admission, authenticated publication/selection/capture, compatible fitted
descendants and application utility. Runtime/proof/package milestones may be
completed only against their respective actual evidence.
