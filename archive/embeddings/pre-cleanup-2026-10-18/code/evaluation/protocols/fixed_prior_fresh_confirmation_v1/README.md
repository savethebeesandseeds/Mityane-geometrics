# Fixed-prior fresh confirmation

This additive protocol measures **RPB-v17.alt-01**, five fresh instances of the
unchanged RPB-v17 design, under the [prospective card](../../cards/fixed_prior_fresh_confirmation_v1.md).
The protected development screen and model headers remain unchanged.

The separate CPU data writer delegates to the authoritative TEMPO-3 generator.
It serializes legal observations, masks, scoring labels and paired source IDs;
the deleted role also stores requested erasures. Clean waveforms and latent
generator parameters are absent. The CUDA producer receives only the legal
Batch, fits its TRAIN scaler and trains once through512. Shared fixed heads fit
the saved native32 tensors on CPU; the saved-only reader performs no fitting.

Use the existing managed container. From the repository's PowerShell launcher:

```powershell
.\container.ps1 -Action exec -Command @('bash', 'code/evaluation/protocols/fixed_prior_fresh_confirmation_v1/admit.sh')
```

Admission prints its exclusive capsule path. It captures62 source files and the
card/verified SDK proof, builds only the new producer/writer and authoritative
generator object, reuses nine unchanged generic shared objects, and runs CPU
data/CUDA engineering gates before generating the complete15-file fresh matrix.
The source-only freeze and post-generation quality freeze must match.

Then run once, using that exact capsule and a new output leaf:

```powershell
.\container.ps1 -Action exec -Command @('bash', 'code/evaluation/protocols/fixed_prior_fresh_confirmation_v1/run_confirmation.sh', '/embedding/output/runs/rpb-fixed-prior-fresh-confirmation/ADMISSION', '/embedding/output/runs/rpb-fixed-prior-fresh-confirmation/NEW_QUALITY')
```

All five masters are mandatory. The named session lock covers CUDA execution
and saved checks. Keep point0/512 checkpoints, scaler, optimizer/RNG/counters,
full loss trace, three feature views, three head fits and both waveform queries.
The reader uses the pinned passed standard-library archive codec and arithmetic.
It checks source/label/split association, legal TRAIN moments, prediction scores,
query MAE and exact12 relation coordinates at0/512 without loading a model.

`publish_confirmation.py` writes compact metadata and the standard result tables
from passed saved checks. `record_confirmation.py` appends the fresh instance
bundle while asserting all historical entries are semantically unchanged. It
refuses to replace an existing bundle. Capture these metadata tools separately
before publication; their source is outside the compiled62-file closure.
