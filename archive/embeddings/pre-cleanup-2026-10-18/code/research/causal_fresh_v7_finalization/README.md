This directory owns complete physical copies of the five V6 finalization files,
then adapts them for CPB-v7.market-01. It imports no V6 finalizer or producer.
No tool here has been executed. Source preparation does not declare a measured
V7 score, leader, audit count or successful condition. A later root-reviewed
input plan must bind actual completed evidence before any metadata arithmetic.
All execution belongs in the existing GPU-enabled cuwacunu Linux container;
these metadata tools themselves perform no model, head, fit or training call.

`prepare_card.py` accepts `--plan PLAN --output NEW_SOURCE_LEAF`. It checks the
root's explicit plan admission, exact input roles and hashes, actual evidence
selectors, original prospective card/descriptor and existing six-file live
snapshot. It copies saved UTF-8 JSON/text bytes and the owned `finalize.py` into
an exclusive leaf, then writes `finalization-card.json` and `card-generation.json`.
It does not generate proposals. The root reviews/admit this generated card
before running `finalize.py --card CARD --output NEW_PROPOSAL_LEAF`.

The finalizer creates exactly three unapplied JSON proposals:

- `doc/clean_causal_encoder_research_ledger.json`;
- `code/encoders/causal_patch_bottleneck_mae/versions/current.json`;
- `code/encoders/causal_patch_bottleneck_mae/versions/instances/CPB-v7.market-01.json`.

Its `finalization-proposal.json` lists output hashes. It cannot apply them,
change a descriptor, promote the application, train a later encoder or publish.
Partial outputs/failure receipts remain in their exclusive leaf; never reuse it.
`review_proposals.py --card CARD --proposals DIR --output NEW_JSON` independently
checks the proposed outputs against saved input tables/history/trust receipts.
It imports no proposer and writes only a new review JSON. Root approval and
separate exact application of those three reviewed proposals remain required.
