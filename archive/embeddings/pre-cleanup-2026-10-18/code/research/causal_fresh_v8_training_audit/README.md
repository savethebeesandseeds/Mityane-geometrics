# Independent saved CPB-v8 training audit

Copyright (c) 2026 Waajacu. All rights reserved. See LICENSE.

This is a complete, independently owned physical adaptation of the frozen V6
saved-training auditor. Its embedded restricted inert C++ archive reader uses
only Python standard-library descriptors. No producer, Torch or NumPy import,
model/optimizer construction, encoder/decoder evaluation, head fit or replay is
performed. Old auditor/model/data/result files remain unchanged.

The auditor source is prepared before any independent arithmetic. Exact main
card/Markdown/input-manifest hashes and actual source-file count are supplied by
its separately frozen audit card, avoiding a source/card SHA cycle. That card
also pins this source/support, main source manifest/ZIP, exact run/attempt/source
paths and preserved parent auditor bytes. Every admitted source member is
verified before saved numeric access. Run only after root admits the completed
main trajectory in the existing managed cuwacunu container. Existing output is
refused; preserve failed attempts and their logs rather than replaying models.

The inherited independent checks retain all2048 B8 row selections and streams,
TRAIN4096 scaler/bank arithmetic and version-aware identities, all77 saved
parameter tensors/76 fresh learned tensors, fixed3888-value literal prior,
frozen statistics,152 AdamW moment tensors and typed512/1024/2048 counters.
The actual512 continuation is checked from source-bound saved evidence without
repeating it. All V8 inference outer/payload and TRAIN root/encoder/payload
levels must contain the exact policy and Long[5] partition[4,16,32,4,8].

All2048 records keep V6's unit F64 Huber1 mean plus detached-error Gaussian
variance objective, separate ordinary reporting NLL and shared global clip1.
Full112TRAIN/32known-VALIDATION fixed-query summaries and bounded first8 saved
query cells retain the declared Gaussian/MAE/component arithmetic. Actual
pre-step update1/2048 component witnesses bind rows, targets, visibility/context
masks and the same hierarchical reductions. Known-VALIDATION tensors are opened
only for unchanged-kernel post-training verification, never mechanism selection.
Raw-cache feature/statistic arithmetic remains strictly TRAIN-only.

The only nonzero-data-gradient exemption is the one-value common softmax bias
core.encoder.level.base.backbone.pool_score.bias. It remains requires_grad and
in the unchanged AdamW. Exactly75 other tensors/294751 values need nonzero
actual CUDA data-gradient events and optimizer movement. Gauge gradients and
movement are observed honestly, without lower bounds or counting decay as
learning. Actual final movement flags are verified against initial/final saved
bytes; no new all-scalar identifiability claim is made.

The additional temporal module independently checks all8192 subgroup CSV rows
(2048 updates x4 bins),2048 scalar-gauge rows, exact original export/position
row memberships, finite norm/count consistency, per-bin event reductions and
both CSV receipt pins. Each of four eight-row export weight/bias slices and
four within-bin-centered position contrasts must have a data-gradient event and
movement during the trajectory; empty-bin updates may legitimately be zero.
Pinned initial/final parameter arrays independently establish final export and
centered-position changes. Gauge step continuity and telescoping movement are
checked separately, with no positive learning requirement.

Twelve actual before/after/clipped-gradient arrays in each existing update1/2048
component witness independently reproduce subgroup norm/count CSV values. Each
F32 before/after operand is promoted to F64 BEFORE subtraction, exactly matching
the frozen producer. Centering is within each original four-position block.
Norm comparison uses absolute2e-12 plus relative2e-12 tolerance. No additional
forward or weight evaluation is needed. Norms for the other2046 updates remain
observed producer evidence; unavailable upstream gradients are not invented.

The retained nonzero CUDA objective fixture and new actual pooling fixture are
bound by binary/log/stage pins and declared PASS tokens. The pooling fixture
has exactly1 backbone Model::encode,2 direct actual-kernel calls,0 public
Encoder/head calls and1 synthetic AdamW step. This does not relabel those
fixture calls as zero model computation. Shared global clipping, decay and
future residual/statistic coupling remain; no optimizer independence is claimed.

--data-root /cuwacunu --audit-card CARD --engineering-proof PROOF
--gradient-proof PROOF --temporal-proof PROOF --output NEW_JSON.
