This complete owned adaptation of the neutral V5 training auditor uses only
Python's standard library and its embedded, restricted inert C++ archive reader.
It imports no producer, Torch or NumPy code and constructs no model, optimizer or
head. Historical auditor and main source bytes remain untouched.

The prospective card fixes the completed main attempt/run/source, main102-file
capsule and auditor hashes before independent arithmetic. Run only inside the
existing managed cuwacunu container, after root confirms main completion. An
existing output is refused. Preserve every failed attempt; no replay or fitting
is a format fallback.

The audit independently verifies all2048 B8 row choices and seed/counter streams,
TRAIN4096 input/bank statistic arithmetic and version-aware identities, all77
serialized parameter tensors and76 learned tensor movement, protected3888-value
literal prior and frozen statistics, all152 AdamW moment tensors and typed
512/1024/2048 progress, and the actual512 resume evidence without repeating it.

V6-specific checks validate the exact Huber(delta1) mean plus detached-error
Gaussian variance objective and typed routing fields. All2048 CSV records must
have finite components, nonnegative Huber, unit component sum, unchanged numeric
reporting Gaussian NLL and the declared shared global-clip1 factor. Variance NLL
and the composite total may be negative. Full112TRAIN/32known-VALIDATION query
scalar summaries and first8 saved query cells per split/stage are checked with
the same Gaussian MAE/NLL kernels, plus the new components.

The saved actual pre-step update1 and2048 witnesses bind rows/masks/context,
F32 distribution/native40 tensors, F64 component scalars and CSV clipping values.
Independent supported-cell/channel/example reductions promote each F32 operand
to F64 before subtraction and skip unsupported cells before arithmetic. They
perform no encoder/decoder evaluation. Known-VALIDATION query tensors are opened
only for this declared unchanged-kernel audit, never for mechanism selection;
raw-cache feature arithmetic is confined to TRAIN.

Scalar equality cannot prove stop-gradient routing: the admitted nonzero CUDA
fixture, typed policies and observed source-bound execution provide that evidence.
The full parameter-gradient arrays are not saved, so the recorded global norm
is observed evidence; only its clipping-factor arithmetic is reconstructed.
One global clip and AdamW retain optimizer coupling, and mean residual changes
affect future variance targets. This audit makes no optimizer-independence claim.

CLI: `audit_training.py --run RUN --attempt ATTEMPT --source MAIN_SOURCE
--data-root /cuwacunu --audit-card CARD --engineering-proof PROOF
--gradient-proof PROOF --output NEW_JSON`. Initial feature/statistic pairings,
fixed-head quality and22 retention gates belong to the separate quality auditor.
