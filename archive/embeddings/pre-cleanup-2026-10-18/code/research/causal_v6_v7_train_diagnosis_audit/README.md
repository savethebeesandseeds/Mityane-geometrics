# Independent saved TRAIN V6/V7 diagnosis audit

The five files are complete physical copies of the prior neutral V5/V6 auditor,
then adapted in this owned directory. The inert reader remains byte exact.
Only local owned archive_reader/component_math modules are imported; there is
no producer/old-auditor import, model execution, Torch/NumPy, fit or replay.
Status: source preparation only. No AST, schema, body or numeric execution has
occurred. A frozen main card, frozen diagnosis pin and independently reviewed
audit-card/source capsule are required before any audit arithmetic.

Exactly49 numeric roles are admitted: one shared TRAIN target archive,20 common
roles for each version, and four trajectory roles for each version. All49 data
pins, the exact card-declared preservation pins and the final V7 preservation
receipt are verified before any tensor storage values are accessed, and checked
again after arithmetic. Mixed query JSON files are decoded whole but only their
train subtree is used. Training-summary files remain preservation-only hashes.

The auditor independently recomputes:

- TRAIN112 native40 coordinate/block population moments, covariance/participation,
  saved fixed-head scores for all four tasks and three repetitions, chronological
  early56/late56 partitions and saved ridge coefficient/block contributions.
  Existing neural predictions are read; no neural weights, forward, new fit,
  ablation predictor or label generation is allowed.
- Initial/final TRAIN112 saved MAE/NLL and Huber1/variance/total component rows for
  BOTH versions. First8 saved tensors verify supported scalar arithmetic and
  association; the other104 rows remain saved aggregate evidence.
- Initial/final first8 masked-query F64 local decoder adjoints. Both versions
  apply Huber1 to mean and detached-error Gaussian NLL to independent uncertainty4.
  Mean-NLL/MAE derivatives are descriptive alternatives. The original256 scalar
  finite-difference plan is unchanged: first16 supported cells in canonical
  b,c,f,h traversal for each of four version/stage pairs; Gaussian mean/variance,
  MAE and Huber1 scalar kernels with inherited positive steps/tolerances.
- Four fixed32-step query bins: pooled supported errors/components/variance,
  per-channel-feature metrics and bin-specific eligible-example/channel/cell
  reductions. Original observed rawF64 means/population deviations and within-bin
  adjacent first differences are separate support. Bins cannot be summed as
  full-loss contributions. No raw-summary label/readout/ablation is fitted.
- Actual saved pre-step updates1 and2048 for BOTH versions: exact input/support/
  timestamp/first-forward association, supported Huber/variance/total/reporting
  components, artifact bindings and observed CSV norm/factor arithmetic. The
  actual update2048 forward used state2047, whose decoder is unavailable; no
  actual-batch decoder adjoint or post-step coefficient pairing occurs.
- Both2048-step CSVs with fixed overall/four512 blocks: exactly update plus six
  V6 columns (components/reporting/globalnorm/factor), or eight V7 columns
  (components/reporting/two branch norms/two factors). No attempt/anchor/seed/
  gradient-coverage CSV values are numerically accessed. V6's unavailable branch
  split is never inferred, and V7 counterfactual global clipping is not computed.

Saved initial/final checkpoints expose only typed policies/layout and bounded
linear decoder/variance coefficients. V7 additionally exposes the five typed
clipping fields. The mean4 and uncertainty4 bases are independent; no cross-basis,
model or stage cosine/orthogonality/conflict claim is admitted. Full parameter
norms are observed logs, not reconstructed gradients. Separate V7 caps permit a
combined norm up to sqrt2, and both runs use one AdamW; no optimizer independence
or scalar loss-ratio dominance is claimed.

Before execution, the independent audit card must have kind
cpb_v6_v7_TRAIN_diagnosis_independent_audit_card_v1 and pin the exact main-card
bytes/SHA, actual saved diagnosis bytes/SHA, and all five owned source files
(audit.py, archive_reader.py, component_math.py, README.md, provenance.json).
The future source capsule must bind the audit card externally, preserve all
failure attempts, and execute only inside the existing managed container.
Main-card hash is supplied through that frozen audit card to avoid a source/card
hash cycle. The source independently checks the main-card kind,49 roles/fields,
TRAIN112/query8/native40 scope, four bins and all actual-batch/CSV limits.
