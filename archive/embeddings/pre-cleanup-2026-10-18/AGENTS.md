# Embeddings component

This is the embeddings component of Mityane geometrics. The repository root's
AGENTS.md, container.ps1, setup.sh and doc/ENVIRONMENT.md govern development.
Use only the managed mityane-geometrics container. This component's container
and setup entries delegate to the root and must not create a separate container.

Keep this component's existing code/, doc/ and archive/ layout. Reusable model
contracts, model-owned research evaluation and reusable operation code remain distinct.
Preserve original model tags, MIT notices, configurations, source capsules,
datasets, checkpoints, failures, measured records and hash-bound bytes.

Read doc/CURRENT_STATUS.md and the relevant frozen protocol before research.
The complete predecessor instructions are preserved in
archive/mityane-migration-2026-10-18/AGENTS.md. Their scientific constraints and
historical evidence remain relevant; their old project paths, container choices
and lifecycle instructions are superseded by the parent environment. Historical
search notes do not initiate a new experiment during a migration or maintenance
task. Keep fitted preprocessing TRAIN-only, fixed heads and protection floors,
and require actual CUDA proof before substantial GPU research. Do not replay
completed experiments to reproduce an existing score.

New named tasks build in /opt/mityane-geometrics/embeddings/build/<session> and
save runs under /mityane/output/embeddings/runs/<session>. Historical ignored
output/, .build/ and .external/ remain intact. The installed SDK and its original
proof stay at /opt/cuwacunu_embedding/libtorch and its original setup directory.
Frozen absolute paths are evidence identities, not instructions to modify
another project. A historical reproduction needs its own reviewed path mapping.

The repository is public; follow the parent publication policy. Reference cleanup
does not authorize a push, visibility change, image publication, dataset or
checkpoint inclusion in Git, or artifact deletion.
