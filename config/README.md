# Configurations

Version non-secret representation, operation, pipeline and evaluation settings
here as they are introduced. Reference observations, datasets, models and
checkpoints by explicit identities. Version preprocessing and geometry alongside
the representation space, and operation parameters alongside their contract.
See the [project design specification](../doc/operations_over_representations_design_spec_v0.1.0.md).

Keep credentials in ignored local environment files or external secret storage.
